# アプリアイコン生成プロンプト(ChatGPT/DALL-E用)

## そのまま貼り付け用プロンプト

```
Windowsのタスクトレイ常駐アプリ「Token Recovery Notifier」のアプリアイコンをデザインしてください。

コンセプト:
- Claude Code CLIの利用制限(レート制限)がリセットされたタイミングを通知するアプリ
- 「待っていた制限が解除される」「再び使えるようになる」という回復・再開のイメージ

デザイン要件:
- フラットデザイン、ミニマルなアイコン(絵文字風/モダンなアプリアイコン風)
- モチーフ: 時計またはリセット矢印(円形の巻き戻し矢印)+ ベル(通知)を組み合わせたシンプルな構図。
  例: 円形の「更新/リセット」矢印の中に時計の針、右上に小さな通知ドット、というような組み合わせ
- 配色: メインカラーは紫〜インディゴ系のグラデーション(Anthropic/Claudeを連想させる落ち着いた紫系)。
  アクセントとして通知を示す明るい緑または黄色の小さなドットを1点だけ使う
- 背景: 透過、または単色の角丸正方形背景(1024x1024のアプリアイコン標準フォーマット)
- 細部を詰め込みすぎない。16x16〜32x32のタスクトレイサイズに縮小しても判別できるレベルのシンプルさにする
- テキストや文字は一切入れない
- 立体感は控えめ(軽いグラデーションや影は可、写実的な3Dレンダリングやスキューモーフィズムは避ける)
- 出力は正方形(1024x1024)、背景は透過PNG希望

参考にしないもの: 時計とベルを別々に大きく2つ並べるような詰め込みすぎのデザイン、リアルな金属質感、企業ロゴ風の複雑な意匠
```

## 補足(必要に応じて調整)

- タスクトレイに常駐する性質上、**小さく表示しても意味が伝わるか**が最重要。生成後は縮小して確認する。
- 現在のプレースホルダーはPowerShellの既定アイコンを流用しているだけなので、専用アイコンができ次第 `src/tray/tray.ps1` の `ExtractAssociatedIcon` 部分を差し替える想定。
- ライトモード/ダークモードどちらのタスクバーでも視認できるよう、背景が透過の場合は明暗どちらでも潰れない配色にする。
